VoxelBeat — Automated Button / Function Test

Loads index.html in the iframe below, then programmatically clicks every button, toggles every checkbox/slider, and cycles every dropdown — while capturing any JS errors, unhandled promise rejections, or console.error calls that result.

Note: this only catches things that break immediately or throw an error. It won't catch things that are "wrong but silent" (e.g. a button that runs without error but does the wrong thing), and some controls (audio uploads, YouTube search results, Supabase-backed playlists) need real network/user data to fully exercise — watch the iframe itself while the test runs too. Best run from the actual deployed GitHub Pages URL, not a local file, so the iframe isn't blocked by same-origin restrictions.
